## 接口和评分

固定架构为 120×550 的 SRB 阵列，使用 `SRB_Inst.json`、`SRB_Port.json`、`SRB_Arc.json`、`SRB_Net.json`、`SRB_Gap.json`。按官方 Q&A，隐藏请求会覆盖架构描述中的各类 output 端口；端点除 `I*` 外的其他类型均可能出现，顺序可能打乱。正式隐藏集原则上与公开集不重复；打榜阶段的 1B 页面将公开 100 万条随机复制扩充。

```bash
bin/estimate -in request.csv -out result.csv
```

输入表头 `From,To`，输出 `From,To,delay`；保留端点和行顺序，输出非负整数，同一引脚到自身为 0。实现支持 LF/CRLF、UTF-8 BOM、末尾无换行、空行；错误表头、额外/缺失字段、未知端口、非法/越界坐标、整数溢出和超长行返回非零，写出失败亦返回非零。端口哈希命中后核对完整名称。

真实延时大于 0 时，逐条准确度为 `100 × (1 - tanh(4 × |estimate-truth| / truth))`；真实为 0 时仅预测为 0 得满分。准确度是平均相对误差得分，不是精确命中比例。

```text
总分 = 0.80 × 准确度 + 0.15 × 时间分 + 0.05 × 一致性分
时间分 = max(0, 1 - 平均CPU秒数 / 1800) × 100
```

正式约 1B 查询运行五次，CPU time 取均值；本地测 user+sys，包含解析和读写的 CPU。单线程、禁止 GPU，内存上限 2 GB，ZIP 小于 100,000,000 B。任一次超过 1 小时或内存超限判无效；30 分钟仅是时间分归零点。五次输出完全一致时一致性为 100，否则为 0。五次一致且 CPU≤1800 秒时，总分可写为 `0.8×准确度 +20 - CPU秒数/120`。

第八/九阶段容器使用精确的 `--cpus=1 --memory=2000000000 --memory-swap=2000000000`；早期 `--memory=2g` 是 2 GiB，历史报告保持原设置。

## 当前算法

基础近似为 `M(源端口,目标端口) + U(端口对)·V(完整位移)`，rank128，V 覆盖 241×1105 位移格点。在线加源 Net/Gap telescope 和墙门候选代价，再用目标端口×预测延时档的小表校准。U 按分量 maxabs 量化为 int16，加载时还原 float32；V 和 M 保持 int16。

第九阶段新增周期架构四方向包络，以及位置、墙门、Net、端口和基线特征的加权 L1 残差。包络无损差分压缩为 17,424,731 B；运行时解码并检查整表 CRC。16 树每树 255 叶，64 树每树 127 叶，输出按原顺序累加 double、舍入后夹到包络；自环及不支持方向保留原回退。

请求按 16 MB 分块，两趟 11-bit 基数排序聚集 V 行，点积使用运行时检测的 AVX2/FMA 内核并保留标量回退。树按 128 条请求一组逐树计算，整数特征以等价整数阈值比较，改善缓存和指令开销。表、架构、校准及包络编入 ELF；正式运行仅依赖镜像已有动态库（含 zlib），不依赖 Python、JSON 或外部模型。

48 条保留位置精确查询相对分为第八阶段 88.050655、16 树 87.936545、64 树 88.578985，结构误差仍需研究。普通位置残差、更多 latent 分量、单棵大树及大叶数少树配置未优于最终方案。过程与负结果见[第九阶段记录](../docs/第九阶段优化记录.md)，泛化证据见[本轮报告](../docs/stage9_generalization.json)。

名称解析覆盖架构的 496 个端口；低秩表对应 208 个源端口与 288 个目标端口。映射不支持的端口方向组合或强制 Net 落点越界时输出 0，这是当前回退行为，尚未用全芯片精确参考证明其对隐藏可达组合的完整性。
