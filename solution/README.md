## 接口和评分

固定架构是 120×550 的 SRB 阵列，来自 `SRB_Inst.json`、`SRB_Port.json`、`SRB_Arc.json`、`SRB_Net.json`、`SRB_Gap.json`。官方 Q&A 说明隐藏请求可能覆盖公开集未出现的 output 端口，端点类型和顺序不能写死。打榜 1B 页面使用公开百万请求随机复制扩充，正式隐藏集原则上不重复。

```bash
bin/estimate -in request.csv -out result.csv
```

输入 `From,To`，输出 `From,To,delay`；保留端点名称、行顺序，输出非负整数，同引脚自身为 0。支持 LF/CRLF、UTF-8 BOM、空行、末尾无换行。错误表头、额外/缺失字段、未知端口、非法/越界坐标、溢出、超长行和写出失败返回非零。

真实延时大于 0 时，单条准确度为 `100×(1-tanh(4×|estimate-truth|/truth))`；真实为 0 时仅预测为 0 得满分。准确度是平均相对误差得分，不是精确命中比例。

```text
总分 = 0.80×准确度 + 0.15×时间分 + 0.05×一致性分
时间分 = max(0,1-平均CPU秒数/1800)×100
五次一致且 CPU≤1800 秒时：总分 = 0.8×准确度 +20 - CPU秒数/120
```

正式约 1B 查询运行五次，CPU time 取均值。单线程、禁用 GPU、内存 2 GB、ZIP 小于 100,000,000 B。任次超过 1 小时或内存超限判无效；30 分钟是时间分归零点。用户另要求额外保留每轮外推低于 30 分钟的最高精度版本。容器精确限制为 `--cpus=1 --memory=2000000000 --memory-swap=2000000000`。

## 当前算法

基础为 `M(端口对)+U(端口对)·V(完整位移)`，rank128，V 覆盖 241×1105 位移格点。U 为 int16 量化、加载为 float32，V/M 为 int16。再处理 Net、Gap telescope 和墙门的真实双分支最小值，之后使用目标端口×延时档校准。

第十一阶段在 `dx=-32..32,dy=-160..160` 分成 12 个互斥区域，边界 `x=[-32,-8,9,33]`、`y=[-160,-48,0,49,161]`，左闭右开。每区独立压缩；用生成距离逆平方的行/列边际和训练端口频率加权。训练/保存 23,321 个训练几何出现的端口组合，其他组合回退旧基线，不用 test 选择端口。

每区可使用直接距离或 refit 基础残差，并按冻结 profile 选择秩。直接模型覆盖处跳过基础内积；残差模型分别舍入基础和局部内积后相加，两者都参与真实双候选最小值。四组匹配消融收益很小，因此保留旧校准，新残差直接匹配 refit 基线。最终表示/秩以 `docs/*_profile.json` 和发布清单为准。

精度版再使用 `|dx|≤64,|dy|≤320` 扣除中区的 40 维残差。它将覆盖扩大到约 66% 请求，但外区低秩收益/成本较差，因此只作精度保留。V 用 lag-12 差分、双字节平面及 XZ 无损封装，运行时调用镜像已有 `liblzma.so.5`。封装前后字节回环与独立矩阵恢复均验证，不降低数值精度。

约 0.6% 请求的强制 Net 落点在墙内，额外使用加权 L1 的 31 叶残差树。默认候选 64 棵，精度版 160 棵；gate 在解析时确定，仅命中才保留额外特征。请求以 16 MB 分块，基数排序聚集 V 行，点积运行时检测 AVX2/FMA 并保留标量回退。局部矩阵随访问预取，直接模型覆盖处跳过基础预取。

基础表、架构、校准和局部模型编入 ELF，无外部模型或 Python 运行依赖。三候选均通过百万行独立 FMA/双分支/墙内参考零差异和 56 条精确查询核对。精度版 48 条保留位置得分 96.329763，仍有结构误差；该样本数量很小。

名称解析支持 496 个架构端口，低秩表对应 208 个源端口和 288 个目标端口。映射不支持的方向或强制 Net 落点越界时输出 0，尚未用全芯片精确参考证明隐藏可达组合的完整覆盖。
