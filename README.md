# eda2026 — 2026 EDA 精英挑战赛「超大规模 FPGA 布局布线延时估算」

本仓库是本赛题（紫光同创，SRB 120×550 阵列）**新一轮技术路线**的工作区。
旧路线（低秩全局表 + 局部残差 + 墙内树）已到瓶颈（官方综合分 96.44 / 96.28），本仓库不复用其代码与模型，
只在 `docs/实验台账.md` 中保留其**基准对照数据**。

## 当前目标

- 官方 1B 综合分 **≥ 98.5**（冲刺 99.0），等效组合：`acc ≥ 99.3` 且 `官方 1B CPU ≤ 110–130 s`。
- 五次输出一致、ZIP ≤ 100 MB、RSS ≤ 2 GB、单线程。

## 技术路线（一句话）

**精确结构复现**：先用离线精确求解器建立"真值工厂"（208 个源端口的全芯片距离场，7.2 GB），
再把延时写成"精确位移度量 + 精确缺陷代数"的 O(1) 整数式；线上不做逐行搜索、不做低秩截断、不做位置盲残差。

详见 [`docs/技术路线与98分计划.md`](docs/技术路线与98分计划.md)，评分口径见
[`docs/评分换算与校准.md`](docs/评分换算与校准.md)，实验记录见 [`docs/实验台账.md`](docs/实验台账.md)。

## 关键事实（详见计划 §2）

| 事实 | 数值 |
|---|---|
| 精确语义 | arc + gap line + 可穿越 block；net 零基础延时；8/8 check golden 全等 |
| 逐行精确成本 | 0.04–1.4 s/行（比 1B 预算慢 2.2×10⁴–7.8×10⁵ 倍） |
| 按源整场成本 | 单源数十秒；208 源 ≈ 1–2 h ⇒ 精确必须离线摊销 |
| 旧路线误差 | acc 98.21、mae 10.53 ps，且按延时桶均匀 ⇒ 必须整体减半 |
| 公开集覆盖 | 113/208 源端口、256/288 目标端口、无 block0 区域 ⇒ 不能用于选型 |
| I/O 地板 | 1M 行纯拷贝 CPU 67 ms（≈67 ns/行） |

## 纪律

1. 模型选择只看真值留出；测试集冻结后只读一次；
2. acc 与 CPU 必须同源自同一 ELF / 同一批基准，禁止跨批次拼接；
3. 每阶段同时报 acc、mae、分桶、表字节、ZIP、RSS、CPU；
4. 速度结论必须 5 轮交错 + 输出哈希；
5. 任何"逐行精确"入口必须过预算闸门（见计划 §3.5）。
