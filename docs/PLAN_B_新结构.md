# Plan B（分支 `plan-b-structure`）：寻找新的数学结构，追上限

起点：`fc8333d`。本分支只做"B：结构性突破"，目标是把 acc ≥99.3 的模型压到
≤256 B/查询、≤50 ns/行（否则按 `docs/实验台账.md` §4.4 的算术，分数不可能过 98）。
Plan A（可交付精简候选）在 `plan-a-lean` 上并行。

## 1. 已知的硬事实（不要再试）

| 事实 | 数值 |
|---|---|
| 逐 cell 低秩（真值） | rank 32 → 2.16 ps，但需 956 MB |
| 全局共享基 | rank 256 → 97.96 封顶 |
| 模式聚类 / 位移 tile / 组合签名聚类 | 全部否证（97.16 / 97.54 / 签名与位移一一对应） |
| Tucker 64×64 | 98.44，246 MB |
| lane 级 G 分解 | rank 256 → 99.03、rank 384 → 99.35（精度足够） |
| lane 模型在线代价 | 13 lane × rank → 300 ns/行，带宽墙；int8 量化失败（88.9） |
| 解析+写 | 152 ns/行（地面 99 ns 读+解析 + 53 ns 写） |

**结论：瓶颈不是精度，是"精度/访存"比。** Plan B 只接受"同样精度下访存降一个数量级"的结构。

## 2. 候选结构（按可验证性排序）

### B1. min-plus 谱结构：把暂态写成临界圈的组合（首选）
假设：`G(s,k,Δ)` 的位移依赖 = `n(Δ)·λ + 首暂态(s) + 尾暂态(k) + 周期项(Δ mod P)`，
其中 `n(Δ)` 由硬币 DP O(1) 得到，`λ` 是临界圈增益，`P` 是回路周期。
- 验证：用精确场对每个 (s,k) 拟合 `n·λ + a_s + b_k + R[Δ mod P]`，看残差能否 ≤2 ps；
- 若成立：参数 = 3×160 + 208 + 160×|P| ≈ 几千个 int16（<50 KB），查询 1 次查表 + 几次加乘；
- 风险：旧工程测过"低参数形态"只有 37.6 ps——但那是 position-blind 的 (pair,Δ) 形态，
  不是 lane 级；lane 级去掉了目标侧变化，值得重测。

### B2. 车道选择的闭式
`argmin_k (G + B)` 是否可由少数几个标量决定（如"目标最便宜的 2 条 lane + 源侧最便宜的 lane"）？
- 验证：从精确 G 统计 argmin 与 (B 排名, G 排名) 的关系，看能否用 top-k 规则 100% 覆盖；
- 若成立：只需读 2–3 条 lane 的系数（≤768 B）→ 300 ns 降到 ~100 ns。

### B3. 位移的精确代数
`G` 是 hop 链的最小代价；hop 位移集合是 {±1,±2,±4,±10}×{0} ∪ {0}×{±1,±2,±4,±12}。
把 `G` 写成 min-plus 多项式（tropical polynomial）在 Δx、Δy 上的闭式，用稀疏矩阵幂/周期延拓求值。
- 验证：在精确场上测"闭式 vs 真值"的逐 ps 残差；
- 这是理论上唯一能同时做到精确与 O(1) 的方向，但数学风险最高。

## 3. 门槛与停止条件

| 步 | 内容 | 门槛 |
|---|---|---|
| B0 | 用精确全端口场建立 lane 级评估台（已完成） | — |
| B1 | 暂态/周期拟合（每 lane 参数化） | 残差 ≤2 ps 且参数 <1 MB |
| B2 | argmin 规则化 | 覆盖率 100%（在 ≥10⁶ 样本上）且只需 ≤4 条 lane |
| B3 | 闭式推导（如 B1/B2 都不成） | 残差 ≤2 ps 且 O(1) 求值 |

**停止条件**：B1/B2/B3 全部无法在 ≤256 B/查询下达到 acc ≥99.3 ⇒
回到 `plan-a-lean` 的现实目标（96.5–96.8），本分支只保留研究记录。

## 4. 纪律
- 全部结论以精确场（208 目标场 + 208 全端口场，已落盘 18 GB）为真值；
- 每步记录参数量、每查询访存字节、残差分布；
- 不与 Plan A 的候选混用数据口径。
