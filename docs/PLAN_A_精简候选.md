# Plan A（分支 `plan-a-lean`）：前沿最优点上的精简候选

起点：`fc8333d`（solution2 的最新提交）。本分支只做"A：可交付的精简候选"，不追上限。
Plan B（寻找新数学结构）在分支 `plan-b-structure` 上进行。

## 1. 目标（现实可达）

| 指标 | 目标 |
|---|---|
| 端到端 | 本机 1B ≤ 210 s（≤210 ns/行），官方 1B ≤ 250 s |
| acc（真值抽样 / 公开 1M） | ≥ 98.0 / ≥ 98.2 |
| 综合分 | **96.5–96.8**（优于旧路线官方 96.44） |
| 约束 | ZIP ≤100 MB、RSS ≤2 GB、5 次一致、单线程 |

依据：`docs/实验台账.md` §4.4–4.5 的实测前沿——解析+写 152 ns/行是地面，
模型必须 ≤50 ns/行（≤256 B/查询）；此配置下 acc 的现实上限约 98.2。

## 2. 模型形态（lean）

```text
delay = exact_gap(x0,y0,x1,y1)                 # 前缀和，O(1)，已精确
      + min(0, wall/overshoot 修正，可选)       # 仅当被实测证明有增益
      + U[pair] · C[cell]                       # int8 点积，rank r
```

- `pair = src * 288 + tgt`（208×288 = 59,904），`cell` = 位移分区索引；
- `U`：rank r × 59,904 int8（全局基），`C`：cells × r int8（逐 cell 系数）；
- 每查询读 2 行（各 128 B，r=128）→ 256 B，与旧路线同级。

**cell 分区的候选（按字节预算取舍）**：

| 方案 | cells | 说明 | 预估 acc |
|---|---:|---|---:|
| R | 120 | (dx mod 10, dy mod 12) | 97.0–97.5 |
| R+D | 960 | 余数 × `|dx|,|dy|` 距离桶 | 97.8–98.1 |
| R+D+S | 2,880 | 再加源/目标墙侧 3 类 | 98.0–98.3 |
| R+D+S+E | 8,640 | 再加四边距离桶 | 98.1–98.4 |

rank r ∈ {96,128,192,256}，与 cells 一起在 100 MB / 50 ns 预算内做网格搜索。

## 3. 分步与门槛

| 步 | 内容 | 通过门槛 |
|---|---|---|
| A1 | 拟合实验：在真值抽样 + 公开 1M 上比较 cell 方案 × rank × 量化 | 找到 (cells, r, 量化) 组合，真值抽样 acc ≥98.0、模型 ≤64 MB |
| A2 | 导出 int8 表 + C++ `estimate`（复用 `bench_lane3` 的解析/写回） | 1M 输出与 Python 参考零差异 |
| A3 | 本机基准（官方镜像，5 轮交错 100M） | 1M ≤210 ns/行；RSS ≤2 GB；ZIP ≤100 MB |
| A4 | 冻结候选 + 5 次一致性 + 边界用例 | 全过；台账记录 |
| A5 | 官方 100M 榜单实测（5 次/日） | 官方 100M CPU×10 ≤250 s 且 acc ≥98.2；否则回 A1 |

## 4. 与旧路线的差别（增益来源）

1. `exact_gap`：前缀和精确，不用近似望远镜；
2. 墙/超调项用精确公式（已由 oracle 验证 308/308）；
3. 真值抽样参与选型，避免公开 1M 过拟合（公开集只作对照）；
4. 量化与 cell 分区在同一预算下做网格搜索，而不是先定形态再压缩。

## 5. 纪律

- 模型选择只看真值抽样与公开 1M 的分离评估；冻结后测试集只读一次；
- acc 与 CPU 必须同源自同一 ELF、同一批基准；
- 每步更新 `docs/实验台账.md`；未过门槛不推进。
