## 复现 P1

以下命令从仓库根目录运行。Windows Python 使用已有环境；WSL 驱动只依赖标准库，编译和推理在评测 Docker 内执行，运行内存限额设为 2,000,000,000 B。

```powershell
& F:\EDA\solution\.venv\Scripts\python.exe solution\tools\displacement_assets.py --source F:\EDA\pango_delay_handover_v3
wsl -d Ubuntu-20.04 -- python3 /mnt/f/EDA/solution/eda2026/solution/tools/displacement_run.py build displacement_baseline
wsl -d Ubuntu-20.04 -- python3 /mnt/f/EDA/solution/eda2026/solution/tools/displacement_run.py run displacement_baseline
& F:\EDA\solution\.venv\Scripts\python.exe solution\tools\displacement_analyze.py displacement_baseline
& F:\EDA\solution\.venv\Scripts\python.exe solution\tools\displacement_oracle_checks.py prepare
wsl -d Ubuntu-20.04 -- python3 /mnt/f/EDA/solution/eda2026/solution/tools/displacement_run.py oracle --queries /mnt/f/EDA/solution/eda2026/solution/build/displacement/oracle_queries.csv
& F:\EDA\solution\.venv\Scripts\python.exe solution\tools\displacement_oracle_checks.py check
```
