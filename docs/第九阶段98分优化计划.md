# 第九阶段：准确度超过 98 的优化计划

2026-10-21 建立，基线为第八阶段 `displacement_cal16`（固定验证 97.638770、测试 97.650829）。本轮直接目标是固定验证/回归准确度超过 98，同时报告源位置留出、精确参考、CPU、包体及资源；不以公开集指标承诺隐藏集分数。

## 假设与实验

1. 旧的端口均值与延时档不足以解释剩余误差。先以当前预测为基线，用位置、完整位移、周期、墙门、Net 落点/超调和端口族训练相对误差加权残差，测少量树与较大模型的准确度/计算量曲线。
2. 将主训练集中的源坐标哈希留出约 20%，并继续排除上一轮三个保留源坐标。新残差参数只在其余训练行拟合，固定验证集选择配置；源坐标留出作迁移检查，固定测试在配置冻结后回归。继承的第八阶段参数曾使用主训练集，因此位置留出只隔离本轮新增参数，不把它称为整个系统的新盲测。
3. 若小模型不足 98，区分表示不足与位置规则错误，再试更丰富残差或合法路径修正；按实测收益决定，保留负结果。准确度是用户本轮首要目标，但仍需满足单线程、2 GB 和 ZIP <100 MB，并报告总分代价。
4. 选定后导出 C++，核对全部公开请求 Python/C++ 逐行预测及保留精确查询；新默认与第八阶段同机交错五轮 10M，完成 11+11 项接口/边界及 ZIP 独立运行验收后发布。第八阶段备份保留。
